# Nest — household money

A private budgeting app for Haytham's household: safe-to-spend, cash-flow forecast with red-zone alerts, envelopes, bills & subscriptions, family plan, dining & trip planner, goals and debt.

**Privacy:** `vault.json` is AES-256-GCM encrypted (PBKDF2-SHA256, 600k iterations). It can only be opened with the passphrase, in the browser, on your device. No statement data is stored in plain text in this repository.

Open it at **https://haytham-mahir.github.io/nest/**
